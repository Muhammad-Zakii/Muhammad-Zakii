## 02 / Featured Project

### `ee-traceability-agent`

**Local AI Agent · Engineering Automation · PDF Intelligence**

[View Repository ↗](https://github.com/Muhammad-Zakii/ee-traceability-agent)

A local AI agent designed for the **On-Board Network Systems & Functions team**. It automates the tedious process of cross-referencing hundreds of hardware requirements against extensive supplier PDF manuals.

The project focuses on making engineering traceability more efficient by helping teams navigate large volumes of technical documentation.

**Key Highlights**

* Automates hardware-requirement cross-referencing.
* Works with extensive supplier PDF documentation.
* Designed for a specialized automotive engineering workflow.
* Focuses on local AI-assisted document analysis.
